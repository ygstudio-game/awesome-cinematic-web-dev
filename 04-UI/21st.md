# 21st.dev

**What it is:** A community-driven marketplace/registry of shadcn-compatible React components, curated and searchable, with many components submitted by designers/developers building modern SaaS and marketing UI.

**When to use it:** Broadest source of pre-built sections (pricing tables, testimonial grids, navbars, footers) when you want a strong starting point rather than building from scratch — pairs well with MagicUI/Aceternity for the more motion-heavy focal pieces.

**When to avoid:** Quality varies more than MagicUI/Aceternity since it's community-submitted — review a component's source before adopting it, don't install blind.

## Install

```bash
npx shadcn@latest add "https://21st.dev/r/<author>/<component>.json"
```

Browse at https://21st.dev to find the component and its install command.

## Common mistakes

- Trusting a component's polish in the marketplace preview without checking its actual code for accessibility gaps (missing focus states, non-semantic markup) — community submissions don't go through the same bar as MagicUI/shadcn core.
- Mixing many different authors' component styles without normalizing to your `@theme` tokens — creates visual inconsistency across sections.
